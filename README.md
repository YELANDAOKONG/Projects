## 🐾 NekoSubscription Suite

> An advanced, multi-platform personal subscription management system designed to track recurring services, renewals, payment schedules, and cash flow projections.

<div align="center">

[![GitHub Stats](https://github-stats-extended.vercel.app/api/pin?username=YELANDAOKONG&repo=YELANDAOKONG%2FNekoSubscriptionWeb&theme=tokyonight)](https://github.com/YELANDAOKONG/NekoSubscriptionWeb)
[![GitHub Stats](https://github-stats-extended.vercel.app/api/pin?username=YELANDAOKONG&repo=YELANDAOKONG%2FNekoSubscription&theme=tokyonight)](https://github.com/YELANDAOKONG/NekoSubscription)

</div>

### 📌 Application Highlights

- **[NekoSubscription (Desktop)](https://github.com/YELANDAOKONG/NekoSubscription)**:
  - Built with **.NET 10** & **Avalonia UI** (declarative markup without XAML).
  - Clean architecture with MVVM pattern (`CommunityToolkit.Mvvm`), EF Core (SQLite), and Serilog.
  - Interactive dashboard, calendar visualization, upcoming payment alerts, and expense projections.
- **[NekoSubscriptionWeb (Web)](https://github.com/YELANDAOKONG/NekoSubscriptionWeb)**:
  - Modern, responsive web frontend built with **Vue**.
  - Unified management interface for subscription planning and financial insights across devices.
